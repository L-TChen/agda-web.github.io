agda-web

A stub page for Agda Web. Our aim is to be able to run an interactive session of Agda the proof assistant in a browser.

Useful links:

  • An experimental PoC on Agda Language Server.
  • Distributions of Agda executable compiled into WebAssembly, for Agda version 2.6.4.3 through 2.8.0; including an alternative setup script to GHC WASM backend. See what patch looks like.
  • A fork of PLFA that can be evaluated in a browser page via vscode.dev or github.dev. Self-hosted version is work in progress.
  • A dark-theme-friendly version of LSP Spec generated via Pandoc.
