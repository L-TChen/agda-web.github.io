agda-web

A stub page for the Agda Web project. Our aim is to be able to run an interactive session of Agda the proof assistant in a browser, powered by GHC's WebAssembly backend.

Demo: type-checking PLFA in VS Code for the Web

You can try out the WebAssembly build of Agda Language Server with PLFA in VS Code. Our fork includes basic configurations to facilitate downloading the minimal set of extensions. Self-hosted version is work in progress.

Steps:

  1. Pick either of the instances:
    • VS Code for the Web (as shown in video)
    • github.dev
  2. (0:14) Open the Extensions tab and check if all recommended extensions are installed and enabled.
  3. (0:33) Run the command Git Submodule Cloner: Initialize and checkout submodules. This fetches the source of standard library into your browser and is persisted across reload.
  4. (0:50) Open a file in src/ and load it with keyboard shortcut ctrl-c ctrl-l.

Implementations

We are working on integrating WebAssembly build of Agda in a variety of IDE/editors:

  • VS Code (desktop/web): agda-mode-vscode by banacorn.
  • CodeMirror 6: In progress! An experimental PoC on Agda Language Server is available.
  • We are working on implementing Agda's interaction protocol on LSP to support all LSP-aware editors at once.
